## Contributing

First, fork the repo and clone the project down to your local machine.

Install dependencies and then start the development server.

```bash
pnpm install
```

To start the server, run:

```bash
pnpm dev
```

Then, open [http://localhost:3000](http://localhost:3000) with your browser to see the result

## Testing Ravelry Integration?
1. Start the server 
```bash
pnpm dev
```
2. Create a tunnel for testing on localhost:
```bash
pnpm run tunnel
```

3. Copy url output URL generated by ***pnpm run tunnel***.

4. Visit https://www.ravelry.com/pro/developer -> 'edit app profile' and add the url generated by ****pnpm run tunnel**** to the list of Authorized Redirect URIs and save.

5. Update **.env.local -> BASE_APP_URL** with the tunnel URL and save.

Troubleshooting: https://www.ravelry.com/discuss/ravelry-api/
